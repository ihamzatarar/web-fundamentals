Critical Rendering Path demo

Open DevTools first (Cmd + Option + I): Console and Network tabs. Then open each experiment.

  1. CSS is render-blocking — blank for 5 s, then blue. Never red.
  2. A plain script is parser-blocking — the paragraph after the script waits.
  3. defer — page shows at once; scripts run after parsing, in order.
  4. async — page shows at once; scripts run as soon as they arrive, any order.
  5. Render tree and layout — in the DOM but not on screen; widths change with the window.
  6. CSS blocks JavaScript — an inline script waits for a slow stylesheet.
